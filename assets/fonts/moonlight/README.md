# Moonlight 제목 폰트

현재 사용: 첨부 ZIP의 `HeirofLightBold.ttf` 원본. CSS 별칭은 `HeirOfLightTitle`, 굵기는 700이다. 내부 이름 `빛의 계승자 / Bold` 및 `우리결혼합니다` 글리프 포함을 확인했다. OTF와 Nymphette는 이전 디자인 자산이며 현재 로드하지 않는다.

- `HeirofLightOTFRegular.otf`, `HeirofLightOTFBold.otf`: 사용자가 제공한 `heiroflight_fonts.zip`에서 추출한 빛의계승자 원본 OTF. 변환하거나 수정하지 않았다. Moonlight hero 제목에만 사용한다.
- `Nymphette.ttf`: Lauren Thompson의 Nymphette. https://www.dafont.com/nymphette.font 에서 다운로드한 원본. 제작자 안내: “This font is absolutely free for personal AND commercial use. Donations are appreciated!” (2026-11-19 확인). 위쪽 q와 아래쪽 e 글리프를 장식으로 사용한다.

장식은 aria-hidden으로 스크린리더에서 제외한다. 기존 SVG 반짝임 애니메이션은 제거했다. 폰트는 프로젝트에서 직접 제공하므로 외부 폰트 서버 연결 없이 로드된다.
