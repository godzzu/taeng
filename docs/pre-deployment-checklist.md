## 발견 원인 및 수정

1. **방명록 비활성화**: supabaseUrl에 Edge Function 경로가 들어 있었지만 현재 클라이언트는 프로젝트 원점에서 REST RPC를 호출한다. 프로젝트 원점으로 수정하여 실제 조회 HTTP 200을 확인했다. 잘못된 함수 경로를 거부하는 회귀 테스트를 추가했다.
2. **지도 버튼 설명 불일치**: 설정된 장소/검색 URL이 길찾기 버튼으로 표시됐다. URL은 유지하고 알려진 Kakao 장소 및 Naver 검색 URL에 맞는 장소 찾기 문구를 사용하도록 수정했다. 직접 길찾기가 필요하면 설정에 목적지 길찾기 URL을 입력한다.
3. **중복 값**: 방명록 검증·글자 수 표시·입력 최대 길이가 같은 GUESTBOOK_LIMITS를 참조하도록 정리했다. document.title 중복 설정은 config-view로 일원화했다. DB의 제한은 서버 검증을 위해 유지한다.
4. **하위 경로 검증 누락**: 서버 테스트에 /wd_letter/ 마운트를 추가해 상대경로와 공유 PNG 응답을 검증했다.
5. **공개 공유 이미지 404**: 점검 시 공개 wedding.png URL은 HTTP 404였다. 로컬 파일과 메타태그는 준비됐지만 실제 배포가 필요하다.

SDK 파일 자체는 HTTP 200이었으나 로컬 브라우저 지도·공유 초기화 성공은 확인하지 못했다. 도메인 등록, API 활성화, 네트워크 및 브라우저 제한을 실제 배포 환경에서 확인해야 하며 특정 원인으로 단정하지 않는다.
