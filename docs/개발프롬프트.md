# AI 개발용 프롬프트

아래 프롬프트는 AI 코딩 도구에 순서대로 전달하여 개발한다. 각 프롬프트는
이전 단계에서 생성한 프로젝트와 파일을 유지하는 것을 전제로 한다.

## PROMPT 01. 프로젝트 기본 구조 생성

``` text
모바일 청첩장 웹사이트를 개발해줘.

기술 스택:
- HTML5
- CSS3
- Vanilla JavaScript ES Modules
- GitHub Pages 배포

프로젝트는 단일 페이지 형태이며 8개 섹션으로 구성한다.

섹션:
1. hero
2. invitation
3. wedding-info
4. gallery
5. location
6. account
7. contact
8. guestbook

요구사항:
- 섹션별 HTML, CSS, JS 역할을 분리한다.
- JavaScript는 ES Module 구조를 사용한다.
- 각 섹션은 독립적인 init 함수를 갖는다.
- 콘텐츠는 별도 설정 파일에서 관리한다.
- GitHub Pages에서 동작해야 한다.
- 상대경로를 사용한다.
- 불필요한 라이브러리를 사용하지 않는다.

다음 폴더 구조를 생성한다.

config/
assets/
css/
css/themes/
css/components/
js/
js/core/
js/sections/
js/services/

우선 프로젝트 전체 파일 구조와 초기 실행 코드를 생성해줘.
```

## PROMPT 02. 디자인 시스템 및 템플릿 구현

``` text
모바일 청첩장의 디자인 시스템을 구현해줘.

템플릿은 2개다.

1. wedding-floral
- 연한 파스텔 블루, 세이지 그린
- 수채화 꽃 일러스트
- 부드럽고 우아한 분위기
- 아이보리 배경
- 섬세한 타이포그래피

2. wedding-sketch
- 블랙&화이트
- 손그림 꽃과 하트 일러스트
- 손글씨 스타일
- 종이 느낌의 흰색 배경
- 미니멀한 레이아웃

요구사항:
- CSS 변수 기반 디자인 시스템을 구축한다.
- templateId로 전체 디자인을 전환한다.
- 공통 레이아웃과 테마 CSS를 분리한다.
- floral.css와 sketch.css를 분리한다.
- 이미지 경로는 assets/images/templates에서 가져온다.
- 모든 섹션에 동일한 디자인 언어를 적용한다.
- 템플릿 변경 시 HTML을 새로 생성하지 않는다.

우선 두 템플릿의 컬러, 폰트, 여백, 버튼, 구분선, 장식 스타일을 설계하고 구현해줘.
```

## PROMPT 03. 설정 파일 구현

``` text
청첩장에 들어가는 모든 정보를 별도의 설정 파일로 분리해줘.

파일:
config/wedding.config.js

관리할 정보:
- templateId
- 신랑 이름
- 신부 이름
- 예식 날짜 및 시간
- 첫 화면 제목 및 이미지
- 초대 문구
- 양가 부모님 정보
- 예식장 이름
- 예식장 주소
- 갤러리 이미지 목록
- 지도 좌표 및 길찾기 URL
- 계좌 정보
- 전화번호
- 카카오톡 공유 제목
- 카카오톡 공유 설명
- 공유 썸네일

요구사항:
- 콘텐츠를 수정하면 별도 HTML 수정 없이 반영되어야 한다.
- 배열 구조를 활용하여 갤러리와 계좌정보를 관리한다.
- 선택 항목의 표시 여부를 설정할 수 있도록 한다.
- 데이터 구조를 일관되게 설계한다.
- 설정 파일과 화면 렌더링 코드를 완전히 분리한다.

설정 파일과 이를 사용하는 config.js를 구현해줘.
```

- 접근성을 고려한다.

- 모달 닫힐 때 원래 상태로 복구한다.

## PROMPT 09. 방명록 개발

``` text
SECTION 08 guestbook을 구현해줘.

기능:
- 작성자 이름 입력
- 축하 메시지 입력
- 메시지 등록
- 메시지 목록 조회
- 작성 날짜 표시
- 글자 수 제한
- 입력값 검증

저장소:
Supabase 또는 Firebase를 사용한다.

요구사항:
- GitHub Pages에서 동작해야 한다.
- 데이터 저장은 외부 서비스 API를 이용한다.
- 서비스 호출 로직은 guestbook-api.js에 분리한다.
- 사용자 입력값을 안전하게 처리한다.
- innerHTML로 사용자 입력을 삽입하지 않는다.
- XSS 공격을 방지한다.
- 스팸 및 중복 등록을 방지할 수 있도록 설계한다.
- API 오류 시 사용자에게 안내한다.
- 모바일에서 작성하기 쉬운 UI를 구현한다.
- Floral 및 Sketch 템플릿을 지원한다.

데이터베이스 테이블 또는 컬렉션 구조도 함께 설계해줘.
```

## PROMPT 11. 전체 통합 및 반응형 테스트

``` text
현재 개발된 모바일 청첩장 프로젝트 전체를 점검해줘.

검토 항목:

1. 8개 섹션 정상 출력
2. 설정 파일 연동
3. templateId 변경에 따른 디자인 전환
4. Floral 디자인 확인
5. Sketch 디자인 확인
6. 이미지 갤러리 및 모달
7. 지도 및 길찾기
8. 계좌 복사 및 토스트
9. 전화 및 문자
10. 방명록 등록 및 조회
11. 카카오톡 공유
12. 모바일 반응형
13. 이미지 로딩 최적화
14. 접근성
15. GitHub Pages 배포 경로

요구사항:
- 기존 기능을 임의로 제거하지 않는다.
- 기존 파일 구조를 유지한다.
- 오류가 발견되면 원인과 수정 내용을 설명한다.
- 중복 코드와 불필요한 의존성을 제거한다.
- 모바일 화면 320px, 375px, 430px 기준으로 확인한다.
- 태블릿 및 데스크톱 화면도 확인한다.
- 최종 배포 전 체크리스트를 작성한다.
```
